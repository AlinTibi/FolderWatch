# FolderWatch v1.1.1

- Adds a distinct FolderWatch application icon embedded in the Windows executable, window and taskbar.
- Fixes cancelled CSV exports overwriting an existing report. Export replaces the destination only after successful completion; cancelled temporary output is removed.
- No changes to snapshot file compatibility or existing workflows.

Windows 10/11 x64. The portable release is self-contained; no separate .NET runtime or WebView2 installation is required.
